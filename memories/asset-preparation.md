# Asset preparation findings

Verified 2026-09-13 while testing the real bundled Corolla through the generic preparation pipeline.

- `design_mod/public/assets/corolla-exploded.glb` contains 88 source primitives, 43 named visual assemblies, 205,990 triangles, six material names, and 11 texture images. Its inventory checksum is `6241f012eddb56546145879b4663b69110ba1749b21623be0db094ecbb8d15f9`.
- The preparation test compares all 617,970 triangle corners after world transforms and display normalization. It also compares every texture image hash, material names, piece membership, and source/output triangle counts. The fixture mapping is `design_mod/tests/fixtures/corolla-mapping.json`.
- The geometry library's `prune()` defaults to `keepSolidTextures: false`. It removes single-color images and folds their color into material factors. This changed the Corolla from 11 textures to 10 even though the source material referenced every image. For exact source-texture retention, use `prune({keepSolidTextures: true, keepAttributes: true})`.
- `COROLLA.md` says the binary was user-supplied. `CAR_LIBRARY.md` separately lists an ItsDiyor Corolla candidate; this does not prove the bundled binary is that creator's asset. The prepared demonstration therefore keeps creator and license unverified, a null download date, and no license URL. It is not one of the four requested Sketchfab source files.
- Explicit `Left`/`Right` source labels establish the fixture's side values. Other source labels have null sides. Damage mapping must treat null-side hood and front bumper families as central assemblies; it must not treat uncertain left/right parts as both sides.
- The preparation command retains unassigned surfaces in a context group. A checksum mismatch or duplicate piece assignment fails before writing a prepared asset. Local demonstration permission is limited to the existing `corolla-prepared-demo` and `ferrari-458-demo` assets; it cannot authorize the requested external source records.
- The bundled Ferrari prepares as 358,788 triangles in four wheel groups plus a context group. Every family is null: wheel groups are not wheel-arch repair trim. Its source checksum is `43564baf3dcf4963adb287d3eeb86729ef966bd5aebf557cdd72117f4f050908`; installed source piece membership, material names, and embedded texture hashes were verified against `public/assets/ferrari.glb`. The record's repair notice keeps Send disabled while allowing the model to be explored.
- The Node server imports the shared registry at startup. Updating the registry can refresh the browser through Vite while the running catalog endpoint still serves old records. Restart the same local server after registry edits, then verify the actual catalog response before diagnosing the showroom.
- A camera fitted to the union of the complete 0–100% explosion range makes the default 50% car unnecessarily small, especially in narrow side-by-side layouts. Fit the current explosion state using each assembly's translated bounds; a combined box has empty corners that also waste space. Preserve the camera direction and relative zoom when refitting. The live viewer check projects actual assembly bounds at 0%, 50%, and 100% and confirms that resizing keeps the selected part and orbit direction.
- The shared showroom pauses its renderer while repair is active. Restoring its canvas to the document is not enough: the All cars handler must explicitly reactivate rendering and resize after revealing the container. The live browser test retains the original canvas identity and checks that real graphics draw calls increase again after returning, which catches a visually frozen canvas even when the document structure looks correct.

Official reference checked 2026-09-13: https://gltf-transform.dev/modules/functions/interfaces/PruneOptions

Ferrari seam topology discovery: source-index connected components (23,633) were misleading because of duplicated vertices. Optional position connectivity reduces to 1,030 intact surfaces, then nearest-major grouping gives 131 assemblies. This is connectivity analysis only: no weld operation or triangle cutting, preserving source material/texture seams. Manual recognizable body IDs are recorded in prepare-ferrari-explosion.mjs; no independent wheel-arch trim added.
